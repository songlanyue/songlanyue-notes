一起交流

我是陈文杰，一名计算机专业的学生。最开始写网页，是因为想把喜欢的东西放在一个属于自己的页面上； 后来慢慢发现，从设计、写代码到买服务器、配 Nginx，把整条链路打通的那一刻才是最有成就感的。

写页面的习惯是先画结构、再调样式，最后逐行检查交互细节； 遇到问题时我会先读文档和源码，把原因搞清楚再动手改，而不是靠试。 我相信真正决定质量的是对细节的耐心 —— 一行间距、一个过渡、一次首屏加载。

这个站点就是我的练习场：纯手写的 HTML / CSS / JS，没有任何框架，没有构建步骤， 部署在一台按量付费的云服务器上，用 Nginx 提供服务，代码托管在公开仓库里。
