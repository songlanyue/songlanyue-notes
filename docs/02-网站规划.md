学号：2026116040164　姓名：陈文杰

## 一、板块与内容规划

### 1.1 定位

一个面向同学、老师和未来实习面试官的个人站点，用于呈现：我是谁、我会什么、我做过什么、怎么联系我。

不做博客系统、不做留言板、不做登录，保持纯静态，保证任何人打开都能秒开。

### 1.2 导航结构（单页锚点）

顶部固定导航，共 6 项，对应页面 6 个区块：

| 导航项 | 锚点 | 内容 |
| --- | --- | --- |
| 首页 | `#home` | 姓名、一句话介绍、核心数据（项目数 / 提交数 / 服务器）、主 CTA |
| 关于我 | `#about` | 个人卡片（头像、方向、在学内容、坐标）+ 三段自述 + 三个量化指标 |
| 技能 | `#skills` | 四张能力卡：前端开发、后端与脚本、工具与协作、部署与运维 |
| 作品 | `#projects` | 三张项目卡：个人网站、待办清单、数据可视化小站 |
| 经历 | `#journey` | 三条时间线：开始接触编程、转向 Web 前端、完成部署闭环 |
| 联系 | `#contact` | 邮箱、GitHub、Gitee + 版权与署名 |

### 1.3 每块的具体内容

**首页**
- 徽章：身份标签（计算机专业 · 2026 级）
- 主标题：「你好，我是 陈文杰」，姓名用渐变强调
- 副标题：一句能力定位 + 一句做事风格
- 按钮：查看作品（主）、联系我（次）
- 数据条：3 个项目 / 20+ 提交 / 1 台云服务器
- 右侧视觉：一个仿终端窗口的代码卡，暗示「这个页面是手写的」

**关于我**
- 左卡片：头像、姓名、身份、方向 / 在学 / 坐标三行、交流入口
- 右正文：为什么做网站 → 我的开发习惯 → 这个站的技术选择
- 底部三格：100% 手写代码、≥5 次 Git 提交、24h 从开发到上线

**技能**
四类能力，每类配一句诚实的说明和 4 个标签：
前端（HTML/CSS/JS/Grid）、后端与脚本（Python/Node/REST/JSON）、工具（Git/GitHub/VS Code/Markdown）、部署（Linux/Nginx/SSH/systemd）

**作品**
每张卡包含：封面视觉、标题、年份、两句话说明、技术标签、在线访问 + 源码入口。

**经历**
时间倒序三条，每条含时间、标题、一句话说明。

**联系**
大面板居中，一句话邀请 + 邮件/ GitHub / Gitee 三个按钮 + 学号姓名署名。

### 1.4 不做的东西（范围控制）

- 不做多页路由，避免需要构建和服务器 rewrite
- 不引第三方 UI 库、动画库、图标库，避免外部依赖失效
- 不做后端接口，纯静态就能满足展示需求
- 不做评论区，减少维护与合规风险

```
┌─────────────────────────────────────────────┐
│ 顶部导航（固定）                              │
│  [SY 松揽月笔记]     首页 关于 技能 作品 经历 联系  [主题] │
├─────────────────────────────────────────────┤
│ #home  首屏                                  │
│   左：徽章 / 大标题 / 副标题 / 按钮 / 数据条    │
│   右：仿终端代码卡 + 两个浮动标签               │
├─────────────────────────────────────────────┤
│ #about 关于我（左卡片 + 右正文）               │
├─────────────────────────────────────────────┤
│ #skills 技能（4 列拼板，1px 缝隙）             │
├─────────────────────────────────────────────┤
│ #projects 作品（3 列卡片）                     │
├─────────────────────────────────────────────┤
│ #journey 学习经历（垂直时间线）                │
├─────────────────────────────────────────────┤
│ #contact 联系（HUD 角标面板）                 │
├─────────────────────────────────────────────┤
│ 页脚（版权 + 技术栈）                          │
└─────────────────────────────────────────────┘
```

### 2.2 文件结构

```
网站根目录/
├── index.html          单页结构，语义化标签
├── css/style.css       全部样式：变量 → 基础 → 组件 → 响应式
├── js/main.js          主题、菜单、滚动、渐显、回到顶部
├── assets/
│   ├── favicon.svg     站点图标
│   └── avatar.svg      头像插画
├── robots.txt          抓取规则
├── sitemap.xml         站点地图
└── README.md           项目说明
```

### 2.3 DOM 层级原则

- 只用 `header / main / section / article / footer` 这类语义标签
- 所有视觉装饰（网格、光晕、扫描线、角标）都用 CSS 伪元素绘制，不增加 DOM 节点
- 卡片内容顺序固定为：视觉 → 标题 → 描述 → 标签 → 链接，便于复用与响应式重排

## 三、风格与配色

### 3.1 视觉方向

**未来科技 / 工业 HUD**：深色石墨底 + 琥珀告警色，像军工仪表盘。参考方向是《明日方舟》一类游戏界面的信息密度与冷峻感。

关键特征：
- 深色背景 + 细网格 + 全屏扫描线
- 琥珀色作为唯一强调色，青绿只用于少量点缀
- 直角为主，局部斜切（`clip-path`）模拟工业面板
- 大量等宽字体标签：编号、单位、时间、技术标签
- 角落 L 形角标（HUD 装饰）

### 3.2 色板

| 用途 | 深色（默认） | 浅色 |
| --- | --- | --- |
| 页面底色 | `#0a0c10` | `#e9ebee` |
| 次级底色 | `#0d1015` | `#e1e4e8` |
| 卡片底 | `#11151c` | `#f6f7f9` |
| 主文字 | `#e9edf3` | `#0f1319` |
| 次文字 | `#a9b4c3` | `#3b4553` |
| 弱化文字 | `#6d7a8c` | `#69758a` |
| 分割线 | `#222a35` | `#c6ccd5` |
| 强调色（琥珀） | `#ffb020` | `#a85f00` |
| 辅色（青） | `#2fd4c4` | `#0d7f76` |

### 3.3 字体与字号

| 层级 | 字号 | 用法 |
| --- | --- | --- |
| 首屏主标题 | `clamp(2.5rem, 5vw, 3.9rem)` | 姓名 + 问候语 |
| 区块标题 | `clamp(1.9rem, 3.1vw, 2.6rem)` | 关于我 / 技能 / 作品等 |
| 正文 | 16px / 行高 1.75 | 段落说明 |
| 卡片标题 | 16.5~17.5px | 技能卡、作品卡 |
| 辅助标签 | 10~12px 等宽 | 编号、单位、技术标签 |

字体族：中文用系统字体栈（PingFang / 微软雅黑），数字与英文标签用 `ui-monospace` 等宽族，形成「数据感」。

### 3.4 版式与间距

- 容器最大宽度 1160px，左右留白 28px（移动端 18px）
- 区块上下内边距 104px（移动端 80px）
- 卡片之间用 1px 缝隙拼贴，制造整块面板的效果，而不是分离的浮动卡
- 首屏上下内边距 172 / 96px，保证第一屏信息完整

### 3.5 动效原则

- 只做「低幅度、慢节奏」的动效，避免浮夸
- 元素进入视口时淡入上移 18px，`IntersectionObserver` 触发，同一组错开 70ms
- 悬停：卡片顶部琥珀线从左扫入、按钮上浮 2px
- 尊重 `prefers-reduced-motion`，系统开启减少动效时全部关闭

### 3.6 规划与实际的差异（说明）

初版视觉走的是浅色现代简约（白底 + 靛蓝渐变 + 圆角）。开发完成后评估认为「像模板站、缺少辨识度」，于是整体推翻重做为现在的工业 HUD 风格。

改版没有改动 HTML 结构，只重写了 `style.css` 并增加浅色主题，说明前期的「内容与装饰分离」这一结构决策是有效的。

## 四、给 AI 的关键提示词

开发过程中用 AI 辅助的部分主要集中在视觉方案讨论、CSS 实现细节和文案打磨。以下是实际使用过的关键提示词。

### 4.1 整体视觉方向

> 我要做一个个人作品站，单页，HTML/CSS/JS 纯手写，不要框架。
> 视觉想做成「未来科技 / 工业 HUD」的感觉，类似《明日方舟》那种军工仪表盘：
> 深色石墨底、网格线、扫描线、琥珀色作为唯一强调色、直角、斜切面板、等宽字体的技术标签。
> 不要花哨的渐变彩虹，不要玻璃拟态，不要圆角卡片。

### 4.2 首屏结构

> 首屏左侧放：身份徽章、大标题（你好，我是 + 姓名渐变）、一句定位、两个按钮、三个数据指标。
> 右侧放一个仿终端的代码卡（带红黄绿三个圆点和文件名），外面浮两个小标签，一个写"手写代码 · 零框架"，一个写"Nginx 已上线"。
> 首屏要能在 1440px 下一屏看到全部内容，移动端自动堆叠。

### 4.3 组件细节

> 技能区不要四张浮起来的卡片，用 1px 缝隙把它拼成一整块面板，悬停时卡片顶部有一条琥珀色线从左扫入。
> 作品卡片的封面不要用彩色渐变，改成深色网格 + 琥珀色线框图，像设计稿的缩略图。

### 4.4 响应式与可访问性

> 断点用 1024 / 900 / 640。900 以下导航折叠成汉堡菜单，640 以下首屏按钮占满一行、数据指标换行。
> 所有交互元素要有 focus-visible 样式；图片要有 alt；开启"减少动态效果"时关掉所有过渡。

### 4.5 文案打磨

> 把我的自我介绍写得更像人说的话，不要"致力于""专注于"这种词堆砌。
> 写三句：为什么做网站、我的开发习惯、这个站的技术选择。口语化，200 字以内。

### 4.6 使用体会

AI 在「给出可执行的方案」上效率很高，比如一次就能生成符合 `clip-path` 斜切的完整 CSS；但它给出的初版视觉偏保守（浅色 + 圆角 + 阴影），需要我把方向讲得足够具体（色值、形状、参考对象）才能得到想要的结果。

真正决定成品观感的，还是反复的截图对比和细节调整：间距、字重、对比度、动效节奏，这些 AI 猜不准，必须自己看。
