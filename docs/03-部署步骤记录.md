## 4. Nginx 配置与语法检查

### 4.1 创建站点目录

```bash
mkdir -p /var/www/mywebsite
```

### 4.2 编写站点配置

```bash
cat > /etc/nginx/conf.d/mywebsite.conf <<'EOF'
server {
    listen 80;
    listen [::]:80;
    server_name songlanyue.xyz www.songlanyue.xyz;

    root /var/www/mywebsite;
    index index.html;

    # 静态资源缓存 7 天
    location ~* \.(css|js|svg|png|jpg|jpeg|gif|webp|ico|woff2?)$ {
        expires 7d;
        add_header Cache-Control "public";
        access_log off;
        try_files $uri =404;
    }

    # HTML 不缓存，保证改完刷新立即生效
    location = /index.html {
        add_header Cache-Control "no-cache, must-revalidate";
    }

    location / {
        try_files $uri $uri/ =404;
    }

    # 禁止访问隐藏文件
    location ~ /\. { deny all; }

    gzip on;
    gzip_comp_level 5;
    gzip_min_length 512;
    gzip_types text/plain text/css application/javascript application/json image/svg+xml application/xml;
}
EOF
```

### 4.3 禁止通过 IP 直接访问

```bash
cat > /etc/nginx/conf.d/00-default-deny.conf <<'EOF'
server {
    listen 80 default_server;
    listen [::]:80 default_server;
    server_name _;
    return 444;
}
EOF
```

> `444` 是 Nginx 的特殊返回码：不返回任何响应，直接断开连接。这样用 IP 或其他域名访问都拿不到页面。

### 4.4 移除默认站点

```bash
rm -f /etc/nginx/sites-enabled/default
```

### 4.5 语法检查与重载


## 附：常见问题与处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 浏览器显示 Nginx 欢迎页 | 默认站点未移除 | `rm -f /etc/nginx/sites-enabled/default && systemctl reload nginx` |
| 403 Forbidden | 文件权限或 root 路径不对 | `chmod 644` 文件、`chmod 755` 目录，确认 root 指向 index.html 所在目录 |
| 404 Not Found | 站点目录多套了一层 | `ls /var/www/mywebsite` 必须直接看到 index.html |
| 改了代码但页面没变 | 浏览器缓存 | `Ctrl + F5`；配置里 HTML 已设为 no-cache |
| 用 IP 访问打不开 | 配置了 `return 444` | 这是预期行为，只允许域名访问 |
| 域名访问提示未备案 | 大陆服务器需 ICP 备案 | 提交备案，通过后自动恢复 |
| 证书签发失败 | 80 端口不可达或域名未解析 | 确认 `curl -I http://域名` 返回 200 后再签发 |

### 6. 与部署相关的两个经验

**① 备案期间不要改动以下内容**

- 域名持有者 / 过户
- DNS 解析指向（必须保持指向备案时登记的服务器 IP）
- 服务器实例（不要释放或更换）
- 网站名称（需与备案信息一致）

**② 带宽计费要留意**

服务器为「固定带宽 + 按流量计费」组合，流量超额会导致欠费并暂停带宽服务，表现为网站突然无法访问。建议定期检查账户余额，或改为固定带宽包月。
