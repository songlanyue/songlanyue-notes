## 截图是怎么来的（可复现）

| 图 | 采集方式 |
| --- | --- |
| show-01 / 02 / 04 | 真实 Edge 窗口最大化后 `PrintWindow` 截取（保留地址栏）。注意：须先 `SetProcessDPIAware()`，否则 150% 缩放下只能截到渲染结果的左上角（表现为画面被放大且右侧被裁） |
| show-03 | 390px 宽的 `iframe` 包裹页面 + `--force-device-scale-factor=2`，headless 截图后裁剪 |
| show-05 | headless 访问仓库 Commits 页（公开仓库无需登录），避免窗口截图里带出本机其它标签页 |

## 两点注意

1. **隐私**：`deploy-13`～`deploy-16` 是手机短信与备案系统截图，含手机号、订单号。提交作业无碍；若要公开发布（如 GitHub），建议先把手机号打码。
